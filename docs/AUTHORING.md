# VLM 워크북 집필 규약 (에이전트 공용)

## 독자
비전(검출·세그·학습 파이프라인·배포)은 능숙하지만 VLM은 처음인 엔지니어. 매 장은 **독자가 이미 아는 것에서 출발**하는 "다리 문단"(예: "YOLO 헤드가 좌표를 회귀한다면, VLM은 좌표를 '말한다'")으로 시작해 새 개념으로 건너간다. 수식은 필요한 만큼만, 직관 먼저.

## 경계 (절대)
공개 사이트입니다. 비공개 수치·비공개 모델·비공개 데이터·업무 맥락은 싣지 않습니다. 공개 논문/공개 모델/공개 벤치 수치만 쓰고 출처(arXiv 등)를 명시합니다. 비공개 자료를 참고했다면 그 수치와 맥락은 전부 제거하거나 공개 사례로 치환합니다.

## 문체
정중한 "~합니다/~입니다"체. 질문은 "~일까요?". 표 셀·배지·버튼은 명사형. 짧은 문장, 직역투 금지.

## 파일 규약
- 장 본문: chapters/NN.html — chapters/02.html 을 템플릿으로 그대로 복제해 구조(레일·헤더·LAB 카드·퀴즈·더 읽을거리·다음 장 예고) 유지. 공용 자산은 assets/css/base.css, assets/js/site.js 를 **수정하지 말고 링크만**. 장 전용 스타일은 본문 <style>에 최소로.
- 실습: assets/js/labs/chNN-<slug>.js — 순수 클라이언트 JS(외부 라이브러리 없음, 예외: 3장 WebGPU는 transformers.js CDN 허용). 캔버스 색은 CSS 변수 읽기, prefers-reduced-motion 존중, 모바일 폭 대응.
- 퀴즈: site.js 의 퀴즈 엔진 규약(02.html 참고: .opts button[data-a], .expl) 그대로. 진행상태는 site.js 가 단일 키(vlmwb_v1)로 관리하므로 장에서 따로 쓰지 않습니다.
- **site.js 의 CHAPTERS 레지스트리·index.html 은 건드리지 말 것** (통합 단계에서 메인이 갱신). 장 제목은 레지스트리의 제목과 일치시킬 것.

## 분량·구성 (2장 기준)
리드 문단 → 다리 문단 → 본문 5~6절(각 절 3~6문단) → LAB 1~2개(장의 핵심을 손으로 만지는 인터랙티브, 각 LAB에 "무엇을 관찰할지" 힌트) → 확인 문제 2~3 → 더 읽을거리 4~8(arXiv 링크) → 다음 장 예고. 그림이 필요하면 SVG/캔버스로 직접 그림(외부 이미지 금지).

## 검증 (각 장 완료 전)
node --check 로 JS 문법, HTML 태그 밸런스, 비공개 용어 grep(비공개 모델명·로컬 경로 등) 0건, 로컬 서버(scripts/serve.sh)에서 장 페이지·LAB 동작 스모크(DOM 셰임 또는 헤드리스 가능하면).
